# Game Overview

## Game Title

CUBIT: Core of the Cosmos

## Genre

Single-player 3D puzzle-platformer.

## Game Concept

CUBIT is a browser-based puzzle-platformer set in the Cubiverse, a mysterious dimension filled with floating cubic platforms and environmental puzzles.

Players control CUBIT, a small floating robot tasked with exploring fragmented worlds and recovering Core Fragments.

## Core Experience

- Explore floating environments
    
- Solve environmental puzzles
    
- Manipulate platforms and mechanisms
    
- Redirect energy beams
    
- Recover Core Fragments
    
- Progress through increasingly challenging levels
    

## Technology

- Three.js
    
- JavaScript
    
- Vite
    
- Blender
    
- GLB assets
    

## Game Structure

- 4 planned worlds
    
- World 01: The Awakening
    
- 11 implemented levels in World 01
    

## Development Priorities

- Gameplay readability
    
- Performance on low-end hardware
    
- Consistent visual direction
    
- Reliable puzzle mechanics
    
- Polished player feedback
